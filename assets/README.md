# 画像アセット

`client/public/assets/` には、実行時にサイトが参照する画像を格納しています。`assets/original/` は提供画像の保管用です。

| ファイル | 種別 | コードからの参照 |
|---|---|---|
| `client/public/assets/two-sword-illustration.webp` | 本番用WebP | `client/src/components/TwoSwordSection.tsx` |
| `assets/original/IMG_1335.JPG` | 元データJPEG | 現行コードでは未参照 |
